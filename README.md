# Custom Programmable USB Macropad

## Objective
Design and construct a 12-key USB mechanical macropad featuring programmable keys, a rotary encoder, and custom microcontroller firmware.

## Engineering Goals
- Develop embedded firmware for keyboard input detection and USB communication.
- Design and validate a custom keyboard matrix and PCB.
- Implement programmable key mappings and reliable switch debouncing.
- Assemble and test a functional keyboard.

## Constraints
- Budget: $50–$100
- Timeline: approximately 5–8 weeks
- Programming: CircuitPython initially, C later
- Hardware: RP2040
- Design software: KiCad
- Initial assembly: solderless breadboard

## Definition of Success
A functional macropad that reliably registers programmed key combinations, communicates over USB, and has documented hardware designs, source code, and validation results.
